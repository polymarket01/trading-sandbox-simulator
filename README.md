# Trading Sandbox Simulator · 沙盒交易所

**以撮合与结算为核心的现货、永续合约模拟交易所。** 用于学习交易机制、验证策略和练习手动交易，所有账户资金均为模拟资产。

## 核心能力

- 价格优先、同价先到先成交。
- 部分成交与跨档成交，剩余数量按订单要求处理。
- 限价、市价、只挂单、立即成交后取消剩余等订单方式。
- 明确的撤改单排队规则与自成交保护。
- 成交衔接资金、费用和持仓；合约配套保证金及持仓约束。
- 流动性策略可替换，虚拟成交流不进入撮合、不改变账户资产。

公开版仅附带**极简四档铺单**。首次运行自动启用 BTC 现货和永续合约，并使用虚拟成交流。

## 快速开始

准备 Python 3.12 和 Node.js 22，在项目目录运行：

```sh
python3 run_demo.py
```

打开 [本机交易页](http://127.0.0.1:5174/paper/trade/BTCUSDT)，使用 `admin / 12345` 登录。现货和合约各有 **1 亿 USDT 模拟资金**。首次安装依赖需要联网，铺单依赖公开行情可用。
